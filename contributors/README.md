# Contributors wall

Everyone who's done their first PR. To add yourself, create `contributors/<your-github-username>.md` with:

```markdown
# Your Name

- GitHub: [@your-username](https://github.com/your-username)
- Domain: AI/ML · Web Dev · Cybersecurity
- First thing I want to build:
```

One file per person = no merge conflicts. Make the file name your GitHub username so it's unique.

>I added my file as a template to let you guys know how to operate
